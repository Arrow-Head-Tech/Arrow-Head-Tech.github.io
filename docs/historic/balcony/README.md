# 📌 Balcony (legacy)

**This folder is a copy of the legacy Balcony project**, originally the standalone repo [Arrow-Head-Tech/BALCONY](https://github.com/Arrow-Head-Tech/BALCONY). It was brought into the Hub (Arrow-Head-Tech.github.io) on the branch `legacy/balcony` for reference.

- **What this is:** The old Balcony — a Node.js SPA (server on port 8080) + Python watcher (watchdog) that monitored a local project folder and showed a "balcony" view of projects. This is **not** the Balcony in use by the Hub today.
- **Current Balcony (in use):** The scanner that feeds the Hub lives at **`balcony/`** at the **root** of this repo (same monorepo): it runs `scan_and_export.py` and writes `content/projects.json`. See [balcony/README.md](../../balcony/README.md) in the main branch.
- **Git history:** The commit history of the original standalone repo is preserved in [GIT_HISTORY.md](GIT_HISTORY.md) in this folder.
