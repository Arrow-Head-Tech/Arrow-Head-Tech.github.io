# Balcony
Balcony is a NodeJS app that provides a server to show-off all your projects in a stylish way.
With Balcony it is possible to checkout all your projects basic info in a Single Page Application.

> Suggested Sections:

## About the project:
Balcony is buit upon NodeJS and Python. NodeJS serves the app (by default at `8080` port);
Python is used to monitor your file system. This monitoring process help Balcony to understand whenever a new project is created, or some document file is updated and reload the web application.
